# Matchday Desktop 3.2 RC1

Release candidate for the Windows Matchday Desktop application.

## Included
- Coventry City and Arsenal club experiences.
- Hosted football dashboard with fixture, form, league table and upcoming fixtures.
- Windows dynamic wallpaper.
- Windows screensaver.
- Multi-monitor screensaver support.
- Configurable screensaver timeout.
- Optional screensaver seconds.
- Club switching and persistent native configuration.
- Unified Settings save workflow.
- Windows startup integration.
- Wallpaper/screensaver restoration paths.
- Release-hardening diagnostics.

## RC policy
RC1 is feature frozen. Only release-blocking or major defects should be fixed before 3.2 final.
