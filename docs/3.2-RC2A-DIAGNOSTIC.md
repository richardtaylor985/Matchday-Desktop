# RC2a Wallpaper Cycling Diagnostic

1. Start with one club and Dynamic Wallpaper enabled.
2. Hibernate Windows.
3. Resume.
4. Change to the other club and Save.
5. Wait for at least two unwanted wallpaper flips.
6. Open `%APPDATA%\matchday-desktop\live-desktop.log`.
7. Send the log for diagnosis.

The JSON-lines log records timestamp, PID/PPID, executable path, argv, native club,
wallpaper PID, renderer club, renderer URL, refresh trigger, and wallpaper setter result.
This distinguishes duplicate processes, duplicate timers, stale renderer state, and
wallpaper changes originating outside the active renderer.
