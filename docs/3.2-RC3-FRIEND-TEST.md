# Matchday Desktop 3.2 RC3 — Friend Test

Please install the RC3 setup EXE normally.

Try:
1. Select a club.
2. Enable Dynamic Wallpaper and Matchday Screensaver.
3. Change club at least twice.
4. Let the PC sleep or hibernate, then resume.
5. Change club again after resume.
6. Leave Matchday running for at least 10 minutes.
7. Confirm the wallpaper never alternates between old/new clubs.
8. Confirm the screensaver still works.

If anything unusual happens, please send:

    %APPDATA%\matchday-desktop\live-desktop.log
