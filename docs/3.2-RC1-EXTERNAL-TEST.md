# Matchday Desktop 3.2 RC1 — External User Test

## Tester rule
Please do not give the tester technical instructions unless they become genuinely stuck.
The purpose of RC1 is to find out whether Matchday Desktop explains itself.

## Test A — First-time install
1. Give the tester only the installer.
2. Ask them to install Matchday Desktop.
3. Leave "Launch Matchday Desktop" enabled.
4. Observe whether Settings opens and whether they understand what to do.
5. Ask them to select a club.
6. Ask them to enable the Matchday screensaver and dynamic wallpaper.
7. Ask them to save.

PASS: no command prompt, PowerShell, source files, registry editing, Node.js or explanation required.

## Test B — Everyday configuration
Ask the tester to:
- change club;
- change screensaver timeout;
- toggle screensaver seconds;
- disable/re-enable dynamic wallpaper;
- close and reopen Matchday Desktop.

PASS: all choices persist and the resulting Windows behaviour matches Settings.

## Test C — Screensaver
- Confirm the screensaver starts after the selected timeout.
- On multi-monitor Windows, confirm every display shows Matchday.
- Confirm seconds obey the saved setting.
- Confirm keyboard/mouse input dismisses the saver.

## Test D — Dynamic wallpaper
- Confirm desktop icons remain native and clickable.
- Confirm the full dashboard fits the monitor.
- Confirm the wallpaper refreshes.
- Switch clubs and confirm the wallpaper changes without checkbox tricks.

## Test E — Restart
Restart/sign out of Windows with startup enabled.

PASS: Matchday resumes the configured behaviour without intervention.

## Test F — Upgrade
Install RC1 over an existing Matchday Desktop installation.

PASS: selected club and user settings survive.

## Test G — Disable and uninstall
Before uninstalling, note the user's original wallpaper/screensaver.
Disable Matchday integrations and then uninstall.

PASS: Matchday leaves no broken screensaver reference/startup entry and restores the user's prior Windows state.

## Bug classification
BLOCKER — install/uninstall failure, data loss, unusable app, broken Windows desktop/screensaver.
MAJOR — core setting does not apply, club cannot switch, wallpaper/screensaver materially wrong.
MINOR — cosmetic/alignment/copy issue with an obvious workaround.

Only BLOCKER and MAJOR issues should prevent 3.2 final.
