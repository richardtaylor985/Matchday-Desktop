# Matchday Desktop 3.2 RC2

RC2 fixes the Dynamic Wallpaper race discovered after Windows hibernate/resume.

- Only one Dynamic Wallpaper renderer may own the Electron single-instance lock.
- Native `selectedClub` is authoritative; a stale hidden renderer cannot overwrite it.
- Resume re-reads native configuration, reloads the current club and refreshes immediately.
- Duplicate launch attempts are redirected to the surviving owner.
- Overlapping wallpaper captures are suppressed.

## Regression test
Coventry -> hibernate -> resume -> Arsenal -> Save. Leave running for at least five minutes.
The wallpaper must remain Arsenal through repeated refreshes. Repeat Arsenal -> Coventry.
